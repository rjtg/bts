**Playable** describes the current browser or explicitly named experiment.
**Agreed direction** describes a design decision that may still need
implementation. **Proposed** marks an option to test. Historical milestone
notes and mockups preserve the evidence from their own builds. Use the current
references above for a route, rule or limit that has since changed. Parameters
in playable pilots remain provisional unless a document explicitly says
otherwise.
