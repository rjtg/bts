# Guaranteed host dates

The Production hiring desk offers an agreement for one draft discussion
or up to three draft editions of the same show. Choose a host portrait
and explicitly select the recording dates. Each selected date fixes that
person in the host role for its recording window. Signing checks normal
availability, existing recordings and agreements, and cash.

The full fees are paid when the agreement is signed. Any unused date is
marked as such and remains paid. The host and date cannot be changed
after signing. The draft may still change guests, theme and resources.
Cast, studio, airtime and any remaining cost still need a production
booking. Booking credits that date's prepaid fee against the production
budget, and reserves only the remainder. The ledger keeps the original
prepayment and the later reserve as separate entries.

The agreement card lists dates, fees and whether a booking used its
guarantee. Production and public Character files link back to the hiring
desk. One-off production without a separate guarantee is still available.
This slice covers discussion hosts. Negotiated rates, options,
cancellation, talent mobility and multi-role drama contracts are future
work.
