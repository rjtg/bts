# Production dossier

The Preparation script file offers Ideas, Scripts and Production. The
Production branch opens casting, recording and delivery. Selecting a film opens
its own project dossier directly on the blotter. Ideas, script work and
production use the Tape file's two-leaf layout and side tabs, with distinct
folder colours. The same project identity persists through each handoff.

## Playable path

| Branch | Papers and actions |
| --- | --- |
| Preparation → Ideas → Draft new | Film asks for a title, description, creative stars and development pace. Series, discussion and newsroom open their existing briefs. |
| Ideas → Existing | See developing and ready ideas. When a film idea is ready, open its writing file. |
| Scripts → Idle | Shows pitches ready for the writing desk. Compare writers, fees and delivery dates. |
| Scripts → In progress | See the due date, committed Funds, and delivery action for a script or revision. |
| Scripts → Finished | Read the script assessment and choose whether to accept it or pay for a revision when one is available. Acceptance opens Cast in the same project. |
| Production → Ready to book | Assign people on Cast, then turn to Booking for the studio and recording time. The call sheet updates with the exact quote. Confirm from the booking page. |
| Production → In progress / Delivered | Follow a booked film to delivery, then open the finished tape in the planner. |
| Production → Work orders | See discussion work orders and use the shared index to reach the discussion brief, hiring, Sway requests, newsroom and facilities. |

The film branch uses a two-leaf spread without the Studio workbook index.
The Writing and Cast papers open the shared photo gallery from each role's
empty or assigned photo spot. Picking a person fills the spot before any
fee or booking is confirmed.
Side tabs and folded bottom corners turn the pages and preserve the
selected paper for the current project stage. On narrow screens, leaves
stack within a spread. Returning to the office keeps the current project
and papers available through **Return to desk papers**. The Production
index also opens **Project files**, with plain buttons to draft or browse
a project.

## Canister and file box

The Production menu uses the shared film can with short icon-and-text
choices on the lid. A cream sticker on the front wall names the active
branch. The hub keeps the contextual icon and adds a Back arrow to restore
the previous branch and its focused choice. Escape or a click beside the
can returns to the prop. A relevant shortcut such as **Desk papers** appears on the lid.

Named projects move to the upright file box. Standalone films have their
own folders. A series has one folder in the box with the relevant episodes
inside it. For example, Scripts → Finished → Harbour Lights opens only
episodes whose scripts are ready for review. Closing a project returns to
the same box and focuses its folder tab when the project still matches the
selected status.

## Agreed next steps and open decisions

Standalone film ideas now take simulated time before appearing on the
writing desk. Opening a ready idea's writing file changes the view without
committing money. The intended organisation is a collection of ideas, scripts and production
projects. Select a status before choosing a named folder, and group dependent
episodes by show. Draft deletion, trashing unused scripts, selling finished
scripts and explicitly promoting a finished script into an idle production
remain proposals beyond the current bounded actions. Keep an idle job and an
in-progress job distinguishable. Free-text pitch consistency review is a
future optional experiment.
The discussion, newsroom and scripted series workflows keep their existing
development timing. See [the film model](original-film.md) for the
provisional pressure and pace equations.
