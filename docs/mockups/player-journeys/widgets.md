# Widget treatment

These are proposals for review. The office remains visible around the work.
Use existing room art and nearly face-on controls. The canister is for a
short choice, a card or folder is for finding something named, and a spread
is for reading evidence and committing an action.

| Widget | Form and hierarchy | Reuse and access |
| --- | --- | --- |

Use the taupe dossier for the selected work and the pencil note for dayparts. | Keep the owned-work canister and file tabs. Use readable row labels on narrow screens. Selection proceeds by Tab and Enter or by tapping a tape. |

Public evidence and a stamped assessment go on separate leaves. | Reuse the dossier, illustrated cards and date stamps. Switching title or page retains the selected listing and offers a clear focus target. |

All draft and locked states use written labels as well as colour. Avoid spending
or placing on selection alone. Escape and a visible close action return to the
originating object. Outside dismissal, where offered, consumes the pointer
event, so it cannot activate the prop underneath. Use the same focus path with
reduced motion and skip only the travel.
