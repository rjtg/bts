## ImageGen reference and prompts

The built-in ImageGen tool used the existing resting office capture as its
edit target. The common direction was to preserve the original viewpoint,
header, furniture and warm lighting, and add a compact projector film
canister beside the Production clipboard, about 215 pixels wide on a
1280-pixel scene. Each lid has three choices labelled IDEAS, SCRIPTS and
PRODUCTION, with SCRIPTS softly active and a clapper glyph in the center.
The sprite uses stepped silhouettes, a small palette, local warm shadow
and bitmap lettering in the style of a late-1980s adventure game.

- **Enamel label.** Scratched brass-grey steel and a circular cream enamel
  label covering three sectors. Rust red active accent and a bevel.
- **Paper index.** Dull silver can and saffron paper label, with three
  directional manila index tabs and tiny fold details.
- **Tally lights.** Charcoal steel and a faded amber label, with three
  small tally marks inset at the rim and one warm enough to signal focus.

## Deeper levels

[Walk through the deeper stills](deeper.html) from Production into Ideas
or Scripts, and then into the finished-script index. They show the
proposed handoff from short categories to named project files.

The built-in ImageGen edit used the enamel can frame as its source. The
prompts kept the same can footprint, rust red active sector, ivory
enamel and full room:

- Ideas changes the lid to **Draft new** and **Existing**. The rim carries
  the branch name and the hub changes to Back.
- Scripts uses **Finished**, **In progress** and **Idle** on the lid with
  its own rim tab and the same return hub.
- Finished scripts keeps the can small and opens an index on the
  blotter. The example shows **A Light in the Window** and **Harbour
  Lights · Ep. 1**, with Sell and Start production shown as proposed
  actions for the selected title.

The [script tray study](deeper.html#picker) shows the title picker as its own
desk prop. The built-in ImageGen edit used the Finished scripts spread as
its source. It replaced the open spread with a shallow wooden tray, broad
typewritten manila tabs and one folder pulled forward. It kept the Scripts
can and room in view. Reading or acting on a script is a separate spread.

The [enamel heading close-up](deeper.html#enamel-heading) tests the branch
name on the lid itself. The built-in ImageGen edit took the Scripts image as
its reference. It asked for a close crop and a flat, curved enamel header
inside the upper rim with SCRIPTS printed on it, above the three choices
and the central Back arrow.

The [outer rim close-up](deeper.html#rim-heading) puts SCRIPTS on the bronze
lip outside the enamel. The built-in ImageGen edit used the enamel study as
its reference, with the instruction to remove the heading band, extend the
three wedges to the inner edge of the metal and use small curved lettering
on the top of the outer ring.

The [side wall close-up](deeper.html#side-heading) locates the branch on
the cylindrical body, facing the player below the lid seam. The built-in
ImageGen edit used the outer rim image as its reference and asked to move
SCRIPTS from the top metal to the brown band between lid and table.

The [full-room side label studies](deeper.html#side-in-room) use the original
Scripts submenu and folder tray stills as separate ImageGen edit targets.
Each prompt asks to preserve the existing tin's shallow profile, rim and
oval perspective, erase the raised plaque, and print SCRIPTS on the visible
front metal below the lid seam. The notebook and tray distinguish the two
states.

The [show file box study](deeper.html#show-file-box) uses the original
side-labelled tray shot as its built-in ImageGen edit target. The prompt
asks for a small cream SCRIPTS sticker on the same vertical side of the
tin, taller wooden sides on the script box and show-level title tabs.
Harbour Lights represents a procedural whose episode scripts may appear
inside the show folder.
