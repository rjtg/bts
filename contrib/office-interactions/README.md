# Station Office interactions

From the repository root:

```sh
npm --prefix web ci
npm --prefix web run build
npm --prefix web run preview -- --host 0.0.0.0
```

Open port 4173 on the preview host. The build needs Rust with the
`wasm32-unknown-unknown` target and `wasm-bindgen` 0.2.130. Use
`WASM_BINDGEN=/path/to/wasm-bindgen` if it is outside the command search path.
The preview serves the last build. Rebuild to see source changes.

## Replay

**Work first.** Open the shelf, choose Fiction, then Series. Open
Neighbourhood Laughs and choose the first episode. On Brief, open Schedule
this tape, One-shot, then Next gap. Edit its time to 18:04 and ad load to
16 minutes. Confirm and open the first offer slip in the resulting Airing
file. After signing, run through the selected airing and inspect settlement.

**Time first.** Open the desk calendar. Set Start time to 18:07 and choose a
programme for that time. Browse all tapes and open Episode 1. Confirm the
booking slip. Close the resulting file, select 18:00 and try Episode 2.
The preview identifies the overlap and Rust rejects confirmation. The
original 18:07 airing stays on the schedule.

**Check the workspaces.** Return to the office, then open Preparation,
Production, Rights, Research, Ledger and Reviews. Close each from its cover
and check that focus returns to its prop. In Rights, select The Corner Shop
and inspect its terms and assessment paper.

## Scope

The wheel uses existing programme categories and recognizable icons.
Individual titles, episodes and people use labels and available artwork.
Weekly recommendations seed the existing weekly editor. Calendar previews
use public schedule and survey evidence, and Rust still validates each
booking. The compact wheel becomes labelled tiles on narrow screens.

Some detailed production and weekly booking fields retain standard inputs
for exact values. The programme adviser still suggests specific
slots from the current survey and gap data. A separate series binder entry
from the shelf and broader airtime briefs remain design work.
